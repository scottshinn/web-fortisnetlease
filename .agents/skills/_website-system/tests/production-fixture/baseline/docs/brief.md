# Production brief

Build a complete fictional Northline Roofing demonstration for homeowners seeking residential roof repair or roof inspection in Birmingham and Troy, Michigan. Primary conversion: a telephone link to the supplied reserved fictional number, +1-248-555-0100. All visible business facts derive solely from the supplied exercise brief.

Scope: `/`, `/services/roof-repair/`, and `/contact/`, with a real missing-page response. Use the supplied palette and system sans direction in `../design.md`. Use shared templates, structured content and Node builtins with `npm run build` and `npm start`. No dependency downloads, network research, public publishing or working contact form.

Accepted implementation requirements: complete initial HTML, responsive pages, accurate titles/canonicals, truthful schema, accessible links and landmarks, route-safe local server, local-only `lead_call` click event on a stable `data-event` attribute, and developer verification before independent technical and visual review.

The number and business are fictional; telephone link behavior can be exercised, but a real lead cannot be delivered. No public office address, hours, reviews, credentials, warranties, response times, years in business or project claims were supplied. None are to be invented.

Publication assumption: local demonstration only, with `noindex, follow` on all pages. Canonical origin is `https://northline.example`. No deployment or external service integration is required for this exercise. Independent QA is assigned by the parent orchestration workflow after implementation handoff.
